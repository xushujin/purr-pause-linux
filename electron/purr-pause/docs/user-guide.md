# 胖猫暂停一下（PurrPause） 用户操作指南

## 1. 什么是「胖猫暂停一下（PurrPause）」？

胖猫暂停一下（PurrPause）是一款桌面休息提醒应用。当你连续使用电脑超过设定时间后，一只胖猫会在屏幕中央走出来，占据你的屏幕，温柔地提醒你：该休息了！

休息倒计时结束后，猫咪会自动离开。你也可以随时手动关闭提醒。

**核心特点：**

- 轻量无打扰 — 平时只在系统托盘安静运行
- 可爱动画 — 透明背景的胖猫走上你的屏幕
- 灵活配置 — 自定义工作时长和休息时长
- 支持自定义 — 可以替换成你喜欢的猫咪视频

## 2. 安装

### 2.1 下载安装包

从项目发布页面下载最新的 `.deb` 安装包。

### 2.2 安装

```bash
sudo dpkg -i purr-pause_1.4.0_amd64.deb
```

### 2.3 安装空闲检测工具（推荐）

为了让应用能准确检测你是否在使用电脑，建议安装：

```bash
sudo apt install xprintidle
```

## 3. 首次启动

安装完成后，你可以通过以下方式启动：

- **应用菜单**：在应用列表中搜索 "胖猫暂停一下"
- **终端**：运行 `/opt/purr-pause/purr-pause`

启动后，应用会：

1. 在系统托盘显示一个猫咪图标
2. 开始在后台计时
3. 自动创建配置目录 `~/.config/purr-pause/`

应用没有主窗口，所有操作通过系统托盘图标进行。

## 4. 系统托盘使用

### 4.1 查看状态

点击托盘图标打开菜单，菜单顶部显示：
- 激活状态（试用中/已激活/未激活）
- 距下次休息的剩余时间（每分钟更新）

### 4.2 右键菜单

点击托盘图标，弹出菜单：

| 菜单项 | 功能 |
|--------|------|
| 试用中/已激活 | 显示当前激活状态 |
| 距下次休息: XX 分钟 | 显示距下次休息的剩余时间 |
| 待办消息（N） | 打开待办消息列表（N 为未读条数） |
| 消息提醒设置 | 打开消息提醒设置窗口 |
| 暂停监控 | 子菜单：30 分钟 / 1 小时 / 2 小时 / 直到手动恢复 |
| 激活/续期 | 打开激活窗口 |
| 设置 | 打开设置窗口 |
| 计时规则 | 打开计时规则说明窗口 |
| 查看日志 | 打开日志文件 |
| 小火箭演示 | 演示小火箭消息提醒动画 |
| 立即测试 | 立即触发猫咪动画（用于测试） |
| 重置计时 | 将当前计时归零 |
| v1.4.0 | 显示当前软件版本号 |
| 退出 | 关闭应用 |

暂停监控期间，菜单显示"监控已暂停"，"暂停监控"变为"恢复监控"。

## 5. 设置

点击托盘菜单中的"设置"，打开设置窗口：

### 5.1 屏幕使用时间

设定连续使用电脑多长时间后触发休息提醒。

- 默认值：45 分钟
- 可设范围：1 ~ 480 分钟

### 5.2 休息时长

设定每次休息的倒计时时长。倒计时结束后猫咪会自动消失。

- 默认值：5 分钟
- 可设范围：1 ~ 60 分钟

### 5.3 动画模式（仅激活用户）

选择猫咪出现的动画方式：

| 模式 | 说明 |
|------|------|
| 右下角走出 | 猫从右下角走入，边走边放大到屏幕中央 |
| 中央淡入 | 猫直接在屏幕中央由小变大淡入出现，并自动适配屏幕宽高 |
| 右侧走出 | 猫从右侧以固定大小走到屏幕中央 |
| 中央走出 | 猫在屏幕中央由小到大走出（默认） |

试用期用户此功能不可用（下拉框置灰）。

### 5.4 开机自动启动

勾选后，系统启动时自动运行 胖猫暂停一下（PurrPause）。Ubuntu 下应用会写入当前用户的 `~/.config/autostart/purr-pause.desktop`，取消勾选会删除该文件。

### 5.5 素材目录（仅激活用户）

已激活用户可以在设置中选择自定义素材目录。选择后，目录下会自动生成一份素材说明文件。

试用期用户此功能不可用（按钮置灰）。

### 5.6 保存设置

点击"保存"按钮，设置立即生效。点击"取消"关闭窗口不保存。

## 6. 激活与序列号

### 6.1 试用期

首次安装后有 7 天免费试用期。试用期内所有基本功能可用。

### 6.2 获取序列号

1. 打开激活窗口（右键托盘图标 → 激活/续期）
2. 窗口中会显示你的 **机器码**（16 位），点击"复制"按钮
3. 将机器码发送给开发者
4. 开发者会根据你的机器码生成专属序列号

### 6.3 输入序列号

1. 在激活窗口的序列号输入框中粘贴或输入完整序列号
2. 点击"激活"按钮
3. 激活成功后会显示授权类型和有效期

### 6.4 注意事项

- 每个序列号绑定特定机器，不可在其他设备上使用
- 序列号格式：以 `PP-` 为前缀，后接 Base64 编码数据，并按每 8 个字符用 `-` 分隔
- 如果提示"序列号与本机不匹配"，说明该序列号不是为你的机器生成的

## 7. 猫咪动画说明

当连续使用时间达到阈值时，猫咪会以设置中选择的动画模式出现（默认"中央走出"）：

### 模式一：右下角走出

1. **猫咪入场** — 一只胖猫从屏幕右下角走出，逐渐走到屏幕中央并放大（所有显示器同时出现）
2. **猫咪休息** — 猫咪到达中央后躺下，循环播放休息动画
3. **倒计时显示** — 屏幕底部显示休息倒计时、"再等 5 分钟"按钮和"精力充沛！"按钮
4. **猫咪退场** — 倒计时结束或你手动关闭后，猫咪淡出消失

### 模式二：中央淡入

1. **猫咪出现** — 猫咪直接在屏幕中央由小变大淡入出现，最终同时受屏幕高度 85% 和屏幕宽度 90% 限制
2. **倒计时显示** — 同上
3. **猫咪退场** — 同上

### 模式三：右侧走出

1. **猫咪入场** — 猫咪以固定大小从屏幕右侧走到中央，不做缩放
2. **猫咪休息** — 到达中央后切换为休息动画
3. **倒计时显示** — 同上
4. **猫咪退场** — 同上

### 模式四：中央走出（默认）

1. **猫咪入场** — 猫咪在屏幕中央播放走路动画，由小到大走出
2. **猫咪休息** — 走路动画结束后切换为休息动画
3. **倒计时显示** — 同上
4. **猫咪退场** — 同上

动画使用透明背景，不会完全遮挡你的屏幕内容。

## 8. 关闭提醒

当猫咪出现时，你可以通过以下方式关闭：

### 8.1 鼠标操作

- 点击屏幕底部的绿色"精力充沛！"按钮立即结束休息
- 点击"再等 5 分钟"按钮延后休息（每次提醒最多延后 2 次）

### 8.2 等待倒计时

不做任何操作，等待倒计时自然结束，猫咪会自动消失。

## 9. 自定义猫咪视频

你可以用自己喜欢的动画替换默认的猫咪！

> **注意：** 设置页选择自定义素材目录仅对已激活用户开放；试用期用户仍可手动替换默认素材目录中的同名文件。

### 9.1 视频要求

- **格式**：WebM 文件，VP9 编码
- **背景**：必须透明（需要 Alpha 通道）
- **建议尺寸**：200~500 像素宽高

### 9.2 替换步骤

1. 准备两个 WebM 视频文件：
   - 走路动画（播放一次）
   - 休息动画（循环播放）

   `walk-zoom`、`walk-flat`、`walk-center` 使用两个视频；`fade-center` 只使用休息动画。

2. 将文件放入素材目录：
   ```bash
   # 使用默认文件名直接替换
   cp 你的走路动画.webm ~/.config/purr-pause/webm/cat-walk.webm
   cp 你的休息动画.webm ~/.config/purr-pause/webm/cat-rest.webm
   ```

3. 或者在设置中选择自定义素材目录（需已激活），选择后目录下会自动生成说明文件。

4. 如果使用自定义文件名，编辑配置文件：
   ```bash
   nano ~/.config/purr-pause/config.json
   ```
   添加：
   ```json
   {
     "thresholdMinutes": 45,
     "breakMinutes": 5,
     "walkVideo": "my-walk.webm",
     "idleVideo": "my-idle.webm"
   }
   ```

### 9.3 制作视频

使用 FFmpeg 导出带 Alpha 通道的 WebM：

```bash
ffmpeg -i input.mov -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 2M output.webm
```

- 走路动画建议 2~4 秒，猫从画面右侧走到左侧
- 休息动画可以是猫趴着、打呼噜等循环动作

### 9.4 素材目录位置

```
~/.config/purr-pause/webm/
```

首次运行后会自动创建此目录，并包含一个 `purr-pause-素材说明.txt` 说明文件。

## 10. 智能计时说明

> 此信息可通过托盘菜单的「计时规则」查看。

胖猫暂停一下（PurrPause） 每 10 秒检测一次你的活动状态，按以下规则判断：

| 条件 | 行为 |
|------|------|
| 动画正在显示 | 跳过，不检测 |
| 用户手动暂停监控 | 跳过，不检测 |
| 屏幕已锁定 | 跳过，不检测；解锁时若锁屏超过 10 分钟则计时归零 |
| 系统休眠后唤醒 | 休眠超过 10 分钟则计时归零；短时休眠继续累计 |
| 距上次鼠标/键盘操作 > 10 分钟 | 计时归零（视为已休息） |
| 距上次鼠标/键盘操作 < 3 分钟 | 计时 +10 秒（视为活跃） |
| 距上次鼠标/键盘操作 3~10 分钟 | 不累加也不归零（暂停） |
| 累计活跃时间 ≥ 设定阈值 | 触发猫咪动画 |

这意味着：
- 看文档、看视频时（3 分钟内没操作）仍然会继续计时
- 去倒杯水（3~10 分钟）计时暂停，回来后继续累积
- 去吃午饭（超过 10 分钟）计时自动归零
- 锁屏后完全不计时；锁屏或休眠超过 10 分钟按已休息处理，计时归零
- 你不需要手动管理计时器

## 11. 常见问题 (FAQ)

### Q: 猫咪一直不出现怎么办？

**A:** 请检查以下几点：
1. 确认应用正在运行（查看系统托盘是否有图标）
2. 确认已安装 `xprintidle`：`sudo apt install xprintidle`
3. 使用"立即测试"功能验证动画是否正常
4. 检查是否已达到设定的时间阈值

### Q: 如何设置开机自启动？

**A:** 右键托盘图标 → 设置 → 勾选"开机自动启动"→ 保存。Ubuntu 下也可以检查 `~/.config/autostart/purr-pause.desktop` 是否存在。

### Q: 可以暂时禁用提醒吗？

**A:** 可以。右键托盘图标 → "暂停监控"，选择暂停时长（30 分钟 / 1 小时 / 2 小时 / 直到手动恢复）。暂停期间菜单会显示"恢复监控"选项。

### Q: 视频播放时卡顿怎么办？

**A:** 可能是 GPU 加速未正常工作。尝试：
```bash
# 检查 GPU 状态
/opt/purr-pause/purr-pause --enable-logging
```
确保你的显卡驱动已正确安装。

### Q: 如何完全卸载？

**A:**
```bash
# 卸载应用
sudo dpkg -r purr-pause

# 删除配置文件
rm -rf ~/.config/purr-pause/

# 删除自启动（如果设置过）
rm -f ~/.config/autostart/purr-pause.desktop
```

### Q: 支持多显示器吗？

**A:** 支持。猫咪动画会同时出现在所有显示器上。

### Q: 可以修改猫咪的大小吗？

**A:** 猫咪大小会根据屏幕宽高自动缩放，最大受屏幕高度 85% 和屏幕宽度 90% 限制，目前不支持手动调整。

### Q: 配置文件在哪里？

**A:** `~/.config/purr-pause/config.json`，你也可以通过托盘菜单的"设置"来修改。
